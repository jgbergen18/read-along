# Read-Along

Read an ebook while its audiobook plays: pages turn by themselves and the words being spoken are
highlighted. This is the stand-alone version that runs on a phone, with no computer needed. After the
first visit it works offline.

**No books are included or uploaded.** Each book is added on the phone from a `.readalong` file
(the EPUB, the audiobook and a word-by-word sync map, made on a PC with the companion tools). The
files are stored on the phone only; reading positions, bookmarks and notes stay on the phone too.

## Using it on an iPhone

1. Open the site in **Safari**, tap **Share → Add to Home Screen**, then open *Read-Along* from the
   home screen (books and offline use belong to the home-screen app).
2. Tap **Add book** and choose a book's `.readalong` file (e.g. from OneDrive in the Files app).
3. Play. It works without internet from then on.
